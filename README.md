# WILDLANDS: SURVIVAL

Первый прототип 2D survival-игры для Android на Godot 4.

## Сейчас в проекте
- Боковая камера и физическое перемещение.
- Процедурный рельеф на основе FastNoiseLite.
- Бесконечная подгрузка чанков вокруг игрока.
- Процедурное размещение деревьев и камней.
- Сбор дерева и камня клавишей E.
- Сенсорные кнопки движения и прыжка.
- Простейший HUD.

## Запуск
Открой `project.godot` в Godot 4.3+ и запусти проект.

## Сборка Android
В репозитории есть GitHub Actions workflow для облачной сборки APK. Открой вкладку Actions, дождись завершения workflow и скачай artifact `WILDLANDS-Android-APK`.

## План развития
Это ранний прототип, не готовая игра. Следующие этапы: ragdoll на физических сегментах и суставах, полноценные спрайты и анимации, биомы и структуры, инвентарь, рецепты, сохранение чанков, погода и системы выживания.
